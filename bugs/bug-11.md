# BUG-11: Хуучин хувилбар линк HTTP 500 алдаатай хуудас нээнэ

Орчин: Уншлагын жагсаалт v2.0, Chromium 159.0.8154.6, Windows 11, 2026-11-18.

Урьдчилсан нөхцөл: өмнөх node app.js процессыг Ctrl+C-ээр зогсоож, Lab7 хавтсанд node app.js гэж шинээр асаасан; анхны 3 номтой, хайлт хоосон.

## Дахин гаргах алхам

1. http://localhost:3000 хуудсыг нээнэ.
2. Доод хэсгийн Хуучин хувилбар линкийг дарна.
3. Нээгдсэн хаяг болон хуудасны агуулгыг харна.

Хүлээгдэж байсан: Спецификацийн дагуу бүх хуудас, линк ажиллана; линк хуучин хувилбарын ажиллагаатай хуудас нээнэ.

Бодит үр дүн: http://localhost:3000/old руу шилжиж HTTP 500, Internal Server Error текст харагдав.

Ноцтой байдал: **Major** — Харагдаж буй навигацийн линкээр зорьсон хуудсаа ашиглах боломжгүй.

Олдсон аялал: **Supermodel**.
