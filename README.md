## Ажиллуулах

app.js нь багшийн Lab07 материал дахь эх файл; өөрчлөөгүй. Нэмэлт сангүй ажиллана.

```powershell
node app.js
```

Браузераар http://localhost:3000 нээнэ. Өөр лабораторийн сервер 3000 порт ашиглаж байвал эхлээд түүнийг зогсооно. Номнууд санах ойд хадгалагддаг тул bug бүрийг шалгахын өмнө Ctrl+C дараад node app.js гэж дахин асаана.

API-ийн нотолгоог дахин гаргахдаа Lab7 хавтсанд:

```powershell
curl.exe -i -X POST http://localhost:3000/api/books -H "Content-Type: application/json" --data-binary "@evidence/bug-03-body.txt"
```

probe.cjs нь браузерээр хар хайрцгийн туршилт хийх туслах код бөгөөд зэргэлдээ Lab1/my-first-test төслийн Playwright, .tools/playwright-browsers санг ашигласан. Аппыг өөрийг нь ажиллуулахад эдгээр шаардлагагүй. Багшийн зааврын .docx болон түр runtime файлууд .gitignore-д орсон.
